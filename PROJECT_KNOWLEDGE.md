3. Confirm the actual live project id/collection shape here before porting any admin-dashboard backend assumption (a Cloud Function name, a collection field, a security rule) across — schema field names, in particular, are already known to diverge (this project has typos like `res_ic` for `res_id` and camelCase `extension_payments` keys that don't match the admin side's conventions; see `PROJECT_ANALYSIS.md` §2 and `IMPLEMENTATION_PLAN.md` §2).
